# 成果与边界矩阵（求职作品视图）

> 一页看清：这套 Skill **已验证了什么、未验证什么、哪些是可复用工程资产**。
> 口径日期：2026-11-25。数据来自本地快照与离线测试，未回填的经营指标如实标「未验证」，不推测补位。

## 1. 项目定位

面向 TikTok Shop 东南亚跨境一件代发的 **Agent 铺货决策流水线**：把未公开 ERP 接口逆向成确定性客户端，
在判断层建立可解释、阈值外置、离线可回归的质量闸门；规则层与接口适配层解耦，规则可跨平台复用，适配层可替换。

- 运行模式：快递助手 ERP 跨境版 + 1688 单件代发 → 国内货代 → TikTok 中转仓；店铺主营家居用品。
- 当前站点：**MY（马来西亚）主攻**；TH/VN 存量维护，不投新品。
- 自动化边界：登录、1688 授权、货代覆盖确认、低置信度整图判定、候选清单最终确认 = 人工接管；其余取数、校验、编辑、发布、回查脚本化。

## 5. 可复用工程资产（与具体 ERP / 平台无关）

- **闸门范式**：本地只读 → 证据列判定 → 退出码阻断 → 阈值外置 YAML；新增站点只换数据源适配，不重写规则。
- **定价模型**：到岸成本拆解 + markup 反解 + 价格带按客单价判定；费率/汇率/成本项外置，改配置不改代码。
- **SKU 身份校验**：跨语言规格名对齐、同价 SKU 防索引错位、不可证身份拒绝回退。
- **失败路由数据飞轮**：规则表 + 黄金集 + 回测命中率；未覆盖案例转人工后回填，规则只收实测案例、不收推测。
- **分层纪律**：判断层（模型可改写）与执行层（确定性可测）只通过 CLI 参数契约耦合；写操作只对点名清单执行，默认 dry-run。
- **离线 CI 门禁**：`scripts/ci_check.sh` 串联测试套件 + 定价自洽 + 契约漂移自检，`.github/workflows/ci.yml` 在 push/PR 触发；不联网、不需 token，WARNING 不阻断、FAIL 才退出非 0。
- **密钥与仓库卫生**：sellerId / 店铺名走 `.env`（已 gitignore），仓库内只留占位；店铺快照为运行时产物不入库；测试 fixture 用占位值，不依赖真实凭证跑通。

## 6. 已知能力缺口与路线图

- **P0（出单优先）**：回流数据采集闭环——罗盘导出回填通道已建（`backflow_import.py`），剩余：按到期时点真实写盘回填存量批次、补齐入池体检留痕；商品卡要素处方（属性补齐、标题词根校验、最小视频方案）；T+0 免费流量三件套留痕；MY 定价地基 UNKNOWN 项核实；履约健康指标口径前置；评估官方 Open API 申请门槛以替代手工导出。
- **P1（作品化，2026-11-25 已落地）**：文档口径统一到 MY 主攻、主文件瘦身分层索引、两层解耦显式化、本矩阵、离线 CI 门禁与源码层脱敏；`ttl_edit --drop-sku` 支持按 SKU 定点剔除破带规格。
- **P2（出单验证后再投入）**：订单后链路（采购单/客服/评价/退款纠纷看板）、达人联盟与广告活动、内容素材生产、竞品监控、选品漏斗经营报表。
