# TikTok Shop 选品策略与评分规则（TH/VN 家居类目）

> 本文件是 tiktok-light-listing 的选品模块。执行 Step 0 选品前必读。
> 原则：**跟趋势不跟爆品、吃细分不吃大类、货架场优先、150款/20天破零**（官方新商方法论）。
> 店铺类目是家居用品（硬约束）：只在家居类目内部选品，禁止跨类目（美妆/3C/服饰等）——跨类目发品会被平台下架甚至处罚。

## 一、选品总原则

TikTok Shop 东南亚跨境新商方法论（官方 2026-01）的三个关键事实：
1. **绝大部分新店首单来自货架场**（搜索+商品推荐），不是内容场 → 选品必须**可被搜索**：标题能堆关键词、类目属性填全。
2. **绝大部分商家上传 150 款商品后才会出首单** → 选品产出量必须够，第一批目标 150 款，不是精选 10 款。
3. **绝大部分商家上品到出单只需 20 天** → 20 天是黄金期，超期无流量无转化的品直接下架换品，不恋战。

铺货式选品本质是**用数量碰概率**：批量铺、快速测、留下有动静的、砍掉没反应的。选品的目标不是"找一个爆品"，而是"找一批出单概率高、竞争烈度低、售后麻烦少"的品。

**四条铁律（东南亚家居场景）：**
- **轻小件优先**：单件 ≤300g（上限 500g）、单边 ≤30cm。SLS 10g 起重续重，超重运费直接吃掉利润。
- **进货价 5-15 元 / 售价 $2-8**：覆盖佣金、物流、退款后仍有 25%+ 利润；客单价高不起来，走量。
- **细分痛点 > 大类红海**：不做四件套/大件收纳/拖把扫帚（大卖垄断+体积运费贵），做桌面收纳、缝隙清洁、厨房小工具、卫浴小物这些细分。
- **避开强季节+无复购**（圣诞装饰等）与**需认证品类**（母婴、美妆个护——本店家居类目也发不了）。

## 二、选品数据源（按优先级）与两条选品路径

### 两条路径总览（先决定走哪条）

| 路径 | 起点 | 流程 | 适用场景 |
|---|---|---|---|
| **A. 榜单驱动**（数据源1为主） | TikTok 热销/飙升/新品榜 | 拉榜单 → 1688同款匹配 → 评分 | 跟趋势走量、榜单已有验证 |
| **B. 关键词驱动**（官方信号 → 数据源1的1688搜索） | 官方后台"未满足需求/低竞争类目/热搜词" | 官方找需求信号 → 遨虾关键词搜1688 → 评分 | **避开热销榜红海、抢占空白供给**（新人首选） |

**推荐新人优先走 B**：官方后台告诉你"哪里有已验证的需求+空白供给"（搜索量几千、在售0款或很少），遨虾关键词直接搜到1688货源，全程不需要挤进已热销品的价格战。实测：10个官方信号词全部可搜到合适货源，链路闭环。

### 数据源1：遨虾(aibuy)接口——拉 TikTok 榜单 + 搜1688现货/关键词（已实测 ✅，最高效）
复用外部榜单/搜索客户端（可选依赖，脚本不在本仓库；纯标准库、免登录、低频只读，也可用任意等价数据源替换）：
- **拉 TikTok 榜单**：`--platform TikTok_XS --site TH/VN`，榜单 `overseas_hot_selling_list_v1`(热销)/`overseas_soaring_list`(飙升)/`overseas_new_product_list`(新品)，类目逐层选（一级含 Home Supplies/Furniture/Kitchenware/Home Improvement 等，注意店铺类目约束）。产出字段：下游标价+折算人民币价、1688同款数、同款中位价、三级类目、图片、rankId——**直接支撑五维评分**。
- **搜1688现货（关键词任意，不限于榜单）**：`search --keyword`（中文品类词）与 `search-image`，直接返回 offerId/起批价/1688月销/评分/起订量/供应商，免登录绕过1688网页验证码。**这是关键词驱动路径的核心动作。**
- **能力边界（实测确认）**：`items` 拉 TikTok 商品必须指定"榜单+类目"，**不支持按关键词搜 TikTok 商品**；关键词搜索只作用于 1688 供应侧。
- 用法、字段与坑（倒挂/拥挤/同款中位价口径）见 shopee `references/api-candidates.md`；AI 按本文件第三/四节筛选打分。
- 该接口还提供 `TikTok_XS` 美/欧站点，但本技能只做 TH/VN。

### 数据源2：TikTok 官方后台工具（浏览器访问，已实测 ✅）——需求信号源
路径都在 `seller.tiktokshopglobalselling.com`（登录态由用户接管，`shop_region=TH` 切换站点）。**用受控浏览器 `bu`（`import aha_browser_use as bu`, `plane="bu"`）访问。**

| 工具 | 路径 | 产出 | 实测状态 |
|---|---|---|---|
| **商品机会中心-高潜力商品** | `/product/opportunity?tab=product` | 热门商品列表：品名(当地语言)、销量(7k+/8k+近似值)、**"无竞争对手"标签**、活动剩余天数 | ✅ 实测可取（无价格、跨品类混推需手工筛家居） |
| **商品机会中心-热门关键词** | `/product/opportunity?tab=trending_keywords` | 关键词、搜索次数、关联商品数、增长率(+1893%)、**"未满足需求/全球趋势/热搜商品"标签** | ✅ 实测可取（关键词维度，关键词驱动核心信号源） |
| **商品机会中心-低竞争类目** | `/product/opportunity?tab=low_competition_category` | 类目、在售商品数(0/少量)、搜索量 | ✅ 实测可取（类目维度：需求大+供给空=蓝海） |
| 关键词榜单 | `/compass/search-analytics/keyword-rank` | 热门/飙升/稀缺关键词 + 搜索量 | ✅ 实测可取，有"稀缺/热门"标签 |
| 商品卡畅销商品 | `/compass/product-card-top-selling` | 类目畅销榜+价格带 | 页面可开，需加载 |
| 商品优化工具 | `/product/optimizer` | 标题/主图优化建议 | 无商品时无数据 |
| 价格诊断 | `/product/price-diagnosis` | 价格竞争力诊断 | 无商品时无数据 |

**用法（关键词驱动路径的起点）：**
1. 打开商品机会中心 → **热门关键词tab**：抄录"未满足需求"（搜索高+商品少）和"热搜商品"词（当地语言）；
2. **低竞争类目tab**：抄录"在售0款/少量+搜索量大"的类目（如浴室小工具、牙刷架）；
3. **高潜力商品tab**：记录带"无竞争对手"标签的家居品（用于榜单路径和交叉验证）。
4. 把抄录的关键词**翻译回中文品类词**（如 นาฬิกาทราย→沙漏计时器、กล่องเก็บเสื้อผ้า→收纳盒），交给数据源1的 `search` 搜1688。

### 数据源3：1688 产品开发工具（浏览器访问，官方跨境选品）
1688 官方针对跨境买家的"产品开发工具"：**跨境排行榜**（跨境热销/飙升）、**同款开发**（输入下游商品链接搜1688同款）、**低价开发**。入口在 1688 跨境版/1688.com 服务市场内（"产品开发工具"）。
- 跨境排行榜 → 直接产出 1688 现货 offer（带价格/月销/供应商）。
- 同款开发 → 把数据源1记下的 TikTok 热销品链接/品名贴入，搜 1688 同款，直接拿 offerId。

### 数据源4：1688 关键词搜索（浏览器，兜底）
数据源1的 `search` 接口通常够用；接口失效/风控时，用数据源2抄录的当地语言关键词翻译回中文（或直接用品类词），在 1688.com / 1688 跨境专供频道搜索（**网页搜索需登录，接口失效时由用户接管登录**），筛"跨境专供 + 一件代发 + 48小时发货 + 退货包运费"。
- 筛选供应商：发货地义乌/广州/深圳优先；先确认能发国际物流、接受 TikTok 售后规则。
- 产出 1688 offer 链接：`https://detail.1688.com/offer/<offerId>.html`。

### 数据源5：ERP/接口（待探测，不做默认）
目标 ERP 是否有独立的 TikTok 选品/货源推荐接口**未实测**，不做默认路径。若后续在 ERP 页面发现"跨境热卖/货源推荐"入口，抓到接口后补 `scripts/erp_client.py` 命令并更新本文件；未抓接口前一律回退遨虾/浏览器。

> **参考：竞品ERP（妙手货盘中心）的做法**——跨境热卖（热销榜/销量飙升榜/趋势新品榜/微创新机会榜）+ 蓝海商品（TikTok/Shopee 高潜力低竞争）+ 跨境产业带货盘。其本质是"下游平台热销/机会信号 → 1688 现货匹配"，与本技能两条路径的组合一致；不引入其接口。

### 关键词驱动路径的执行细则（路径B，已实测 ✅）

1. **取需求信号（官方后台，浏览器）**：抄录"未满足需求"关键词、低竞争类目、热搜词（泰文）→ 翻译成中文品类词。
2. **搜1688货源（遨虾 `search`）**：对每个关键词执行 `python3 scripts/aibuy_rank_client.py search --keyword "<中文品类词>" --pages 1 --out ./aibuy_data/tiktok_kw_driven`。
3. **AI筛选打分**：红线剔除（注意宗教/敏感词，如十字架装饰——官方"未满足需求"会混入红线词）→ 同类硬过滤（搜索会混入无关品，只保留品类匹配的）→ 按五维评分取每个关键词的最高分offer。
4. **落盘**：候选清单写 `erp_data/selection_candidates_kw.csv`（字段与路径A一致，额外加 `kw_source` 记录信号来源）。
5. **类目归属核查**：官方关键词标注的类目可能与家居店铺类目不完全一致（如沙漏官方标"钟表"），上架前按"实际家居用途"选类目（厨房计时器/家居摆件），拿不准的不发。
6. **破零节奏**：与路径A产出合并进 150款/20天 节奏，优先铺高分项。

**已知局限（实测）**：官方搜索量是泰国站全局需求，不是本店流量，仅作方向信号；"在售0款"可能是平台禁售类目，需结合红线与平台规则复核。

## 三、硬红线自动剔除（命中即跳过，不进入打分、不询问）

出现以下任一类，AI 自动跳过该品、不进候选清单：

1. **品牌侵权/IP联名**：标题或主图含知名品牌名、贴牌、"正版/联名/授权"字样；知名卡通/动漫/影视角色形象（Hello Kitty/迪士尼/漫威/宝可梦/奥特曼/三丽鸥等）**标题+主图双查**，认不准保守跳过，不赌授权。
2. **液体/膏体/化工**：清洁剂、洗衣液、精油、香水、胶水液体、香薰液等（物流与合规受限）。
3. **电池/带电**：充电件、含电池电子件、插电小家电（新人避开；物流贵+限制多+售后麻烦）。
4. **食品/保健/医疗**：直接入口、药品、医疗器械、宠物零食主粮。
5. **宗教/民俗敏感**：宗教用品、祭祀用品、政治敏感图案。
6. **超重/易碎**：陶瓷碗盘、玻璃制品、大体积重物（运费与破损风险高）。
7. **活物/种苗**。
8. **多规格价差必超限**：卷材/管材/按尺寸选/按磅数分档类（1688 会自动生成几十个 SKU，价差超平台限制，发布必败）。
9. **平台限售需认证**：母婴、美妆个护、食品接触需认证的品类（东南亚多站限售）。
10. **跨类目**：家居店铺类目外的品（美妆/3C/服饰/食品等）——类目是店铺硬约束，直接跳过。

判定拿不准时（尤其 IP 形象认不准），**保守跳过、不发布**，记录跳过原因。

## 四、五维评分规则（AI 打分排序，取高分进清单）

通过红线后，对候选品按五维打分（各 1-10 分，权重见 `config/selection.yaml`）：

| 维度 | 权重 | 评分要点 |
|---|---|---|
| **市场需求 demand** | 0.25 | TikTok 关键词搜索量/榜单热度/销量（商品机会中心销量 7k+ 高分）；Google趋势上升中加分 |
| **竞争度 competition** | 0.25 | 标"无竞争对手"满分；"稀缺"词高分；1688 同款数 100-1500 最佳，≥3000 剔除，<100 供给不足降分 |
| **利润空间 margin** | 0.20 | 售价(折算人民币)/采购价 ≥3.5(TH)/3.0(VN) 满分；用 `config/pricing.yaml` 加价系数反推是否覆盖扣点+物流+退款 |
| **物流友好 logistics** | 0.15 | ≤300g 且 ≤30cm 满分；越靠近上限降分；易碎/玻璃直接出局（红线） |
| **破零速度 breakzero** | 0.15 | 消耗品/复购品加分（粘毛器/洗衣袋/清洁耗材）；需求稳定加分；标题可堆关键词、货架场可搜到加分 |

**排序输出**：综合分 = Σ(维度分×权重)，降序排列；前 N 名进候选清单（N 由任务指定，默认第一批 150）。

**同一批内去重**：标题归一化（去规格/促销/品牌词）后近似、主图雷同的判为同款，只保留最高分 1 个。

## 五、TH/VN 站点差异与家居类目适配

### 站点差异（影响价格区间与选品倾向）
| 维度 | TH 泰国 | VN 越南 |
|---|---|---|
| 客单价 | $2-8 | $1-6（更敏感） |
| 进货价区间 | 5-15 元 | 3-12 元 |
| 优势 | 新店前30天免佣(上限1000THB) | 新店前90天免交易手续费(上限3000万VND)；物流最便宜 |
| 注意 | 佛教文化，图案避宗教雷区 | 语言越南语，标题靠机器翻译；对"划算/实用"更敏感 |

### 家居类目内部优先方向（东南亚实测 + 官方家居选品材料）
**第一梯队（出单快、竞争小）：**
- 桌面/工位收纳：理线器、桌面分格收纳盒、抽屉分隔板、桌下粘贴抽屉、免打孔理线夹
- 厨房小工具：硅胶折叠漏斗、硅胶保鲜盖、量勺量杯套装、壁挂调料盒、挤牙膏器
- 缝隙/细节清洁：窗槽清洁刷、键盘清洁泥、杯刷长柄、门后拖鞋架

**第二梯队（利润稍高、需内容配合）：**
- 卫浴小物：免打孔牙刷架、沥水肥皂盒、浴室手机防水盒
- 装饰小物（轻小件）：电池款LED串灯、自粘墙贴、免打孔挂钩、透明小花瓶
- 洗衣/衣物护理：洗衣袋套装、可撕粘毛器、多层魔术衣架、手动除毛球器

**避开（家居类目内红海/坑）：**
- 四件套/床上用品（大卖垄断价格战）、大件收纳箱衣柜（重）、拖把扫帚水桶（体积大）、大型家具（物流售后搞不定）、清洁剂洗衣液（液体限售）、香薰蜡烛（易燃限售）、玻璃陶瓷装饰（易碎）。

## 六、破零节奏与铺货清单结构

### 节奏（对齐官方 150款/20天）
1. **第一批（第 1-7 天）**：铺满 150 款。按方向分配：桌面收纳 40 + 厨房小工具 40 + 清洁小工具 30 + 卫浴 20 + 装饰/洗衣 20。
2. **第 7 天看数据**：后台看曝光/点击——有点击没加购买家：换主图/调价；没流量：记录，等 20 天节点。
3. **第 20 天节点**：仍无曝光无转化的下架换品（黄金期已过）。有出单的品重点优化+配短视频。
4. **第二批（第 20 天后）**：补 50 款，用第一批验证过的方向/关键词放大。

### 新店免费流量（上架后立刻做）
- 设**新品折扣**（早鸟价）：平台给流量扶持。
- 完成**销售加速中心**任务：投稿/报名活动拿流量券和频道展示位。
- 标题写满 40 字符以上：核心词+属性词+促销词+功效词（用关键词榜单的稀缺/热门词）。

## 七、输出格式（候选清单 → Step1 采集）

选品产出一个候选清单文件（CSV/JSON，落盘 `erp_data/selection_candidates.<ext>`），每行：

| 字段 | 说明 |
|---|---|
| `offer_id` | 1688 offerId（Step1 collect 的输入） |
| `offer_url` | `https://detail.1688.com/offer/<offerId>.html` |
| `title_zh` | 1688 标题（精简） |
| `category_dir` | 家居类目细分方向（桌面收纳/厨房/清洁/卫浴/装饰洗衣） |
| `price_cny` | 1688 起批价（元） |
| `region` | TH / VN（可同品两站都铺） |
| `score` | 五维综合分 |
| `score_detail` | 各维度分（demand/competition/margin/logistics/breakzero） |
| `reason` | 入选理由（命中哪些加分项/标签） |
| `redline_check` | 红线检查结果（pass + 核查要点） |
